## 🔨 省赛前补齐（4 项，优先级降序）

### 1. 接入真实金融数据源（P0）

**当前**：Agent 仅靠 DeepSeek 联网搜索获取文字信息，无结构化金融数据。
**目标**：接入 1 个免费/低成本数据源，让 Agent 能获取股价、财报、宏观经济指标等结构化数据。

**推荐方案**：Tushare Pro（社区版免费，覆盖 A 股行情/财务/宏观）
**需改动文件**：
- `backend/app/services/data_connector.py`（新建）
- `registry.py` 新增 `data-connector` Agent
- `orchestrator.py` Commander 任务规划中加入数据获取步骤

**预估工时**：2-3 天

### 2. 新增 4-6 个 Specialist Agent（P1）

**当前**：6 个 Agent（宏观、行业、基本面、消息面、财富顾问、报告合成）。
**目标**：扩展至 10-12 个，覆盖更多金融场景。

**候选新 Agent**：
| 新 Agent | 用途 | 工行关联场景 |
|----------|------|------------|
| 合规审查师 | 检查分析结论是否符合监管要求 | 信贷审批、产品销售 |
| 反欺诈分析师 | 识别异常交易/诈骗模式 | 智能风控 |
| ESG 分析师 | 绿色金融/可持续发展评估 | 绿色金融赛道 |
| 信用评估师 | 企业/个人信用画像分析 | 普惠金融 |
| 养老金规划师 | 养老金融产品配置 | 养老金融 |
| 跨境金融分析师 | 汇率/跨境支付/贸易融资 | 跨境金融 |

**需改动文件**：
- `registry.py` 新增 `AgentInfo` + `SPECIALIST_PROMPTS`
- 前端 Agent 页面路由自动生成

**预估工时**：1-2 天（每个 Agent 1-2 小时写系统提示词）

### 3. Agent 链式调用（P1）

**当前**：Commander 将子任务并行分派给 Specialist，但 Specialist 之间无法传递结果。
**目标**：支持"A 的输出作为 B 的输入"的串行模式。场景："先分析新能源汽车行业 → 再据此筛选受益零部件公司 → 然后对筛选结果做基本面分析"。

**需改动文件**：
- `orchestrator.py` Commander prompt 增加"依赖关系"字段
- `agent_runner.py` 新增 `run_agent_chain()` 函数
- `agents.py` 新增 `POST /api/agents/analyze-chain` 端点

**预估工时**：2 天

### 4. K 线/趋势图前端可视化（P1）

**当前**：报告纯文本 + Markdown 表格，无图表。
**目标**：综合报告中嵌入 K 线图、趋势折线图等。

**推荐方案**：ECharts 或 Recharts，轻量集成。
**需改动文件**：
- `frontend/src/components/` 新增图表组件
- `MarkdownRenderer.tsx` 支持图表渲染
- 后端 `report-synthesizer` prompt 中引导生成图表数据

**预估工时**：1-2 天

## 校赛答辩风险清单

| 风险 | 等级 | 应对 |
|------|------|------|
| 评委质疑"无真实数据" | 🔴 高 | 强调 DeepSeek 联网搜索可获取最新公开数据，结构化数据源已列入省赛规划 |
| 评委要求看 PDF 打印效果 | 🟡 中 | 以屏幕演示替代，不在答辩时打印 |
| 评委问"和 ChatGPT 有什么区别" | 🟡 中 | 准备 30 秒电梯演讲：多 Agent 协作 vs 单模型对话、可追溯 vs 黑箱、可编排 vs 一次性 |
| 系统现场崩溃 | 🟡 中 | 提前录制演示视频作为备份 |
| 评委质疑商业模式 | 🟢 低 | 强调 SaaS + 私有化部署双模式，对标工行"工银智涌"体系 |

## 校赛前建议准备的材料

1. **6-8 张产品截图**（Dashboard / Agent 分析 / 任务详情 / 搜索引用 / 侧边栏）
