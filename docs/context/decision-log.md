# Decision Log

## LOCKED

- 弈金不再以“报告生成器”为产品中心。
- 核心定位改为“面向 A 股投研人员的研究判断工作台”。
- 报告是导出物，判断资产才是产品核心。
- 不继续以增加 Agent 数量作为主要差异化。
- 当前第一阶段围绕 `ResearchSubject / Claim / Assumption / Evidence / Challenge / DecisionMemo` 落地。
- 分析可以使用上传材料，但产品不在前端刻意标注和暴露“使用了哪些材料片段”的内部处理过程。
- 公司研究驾驶舱内的 AI 分析结果应沉淀为结构化判断资产，而不是只生成一份 Markdown 报告。

## ASSUMPTION

- 首版公司研究驾驶舱允许用户手工录入判断、假设、挑战和备忘录。
- 首版自动生成判断资产先使用研究对象下的页码级材料文本，不额外引入结构化财务数据库。
- 前端保持克制、密集、可扫描的投研工作台风格。

## OPEN

- 是否将 Dashboard 首页完全替换为公司研究入口。
- 自动生成判断资产的真实模型输出质量、提示词稳定性和核验流程。
- 判断资产与具体证据页码/片段的显式引用关系。
- 研究对象与旧 Task/Commander 流程如何深度融合。

## REJECTED

- 暂不做自动交易。
- 暂不做个人化买卖建议。
- 暂不以扩展更多 Agent 作为下一阶段重点。
- 暂不做全量结构化财务数据库接入。
