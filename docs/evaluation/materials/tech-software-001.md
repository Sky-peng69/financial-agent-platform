# 合成企业尽调材料：北辰工业软件

材料属性：合成样例，仅用于验证企业金融尽调流程，不代表真实企业、公告或授信依据。

## 企业概况

北辰工业软件向制造企业提供订阅制生产管理系统和实施服务。材料显示，公司客户续费率下降，同时计划建设区域交付中心并扩大研发团队。

## 模拟经营数据

- 2024 年营业收入：5.3 亿元；订阅收入占比：58%。
- 合同负债：1.4 亿元；前五大客户收入占比：39%。
- 客户净收入留存率：92%，较上年下降 6 个百分点。
- 区域交付中心预算：3,500 万元，预计分两期投入。

## 风险与核验线索

续费率下降可能影响经常性收入和现金回款，交付中心投资会增加固定支出。应核验客户流失原因、合同负债履约、应收账款账龄、研发资本化政策和分期投资安排。以上数字为模拟数据，正式判断必须回到真实合同、财报和客户访谈。
